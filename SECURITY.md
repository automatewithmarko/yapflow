# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Email **contact@thementorprogram.xyz** with:

- the affected version and platform;
- clear reproduction steps;
- the impact you believe is possible; and
- any suggested mitigation.

Please allow the maintainers time to investigate and publish a fix before
sharing the report publicly.

## Supported versions

Security fixes are shipped through the latest official YapFlow release. Update
to the newest version before reporting a problem that may already be fixed.

## Release authenticity

Official desktop updates must pass Tauri's updater-signature verification.
macOS releases are additionally signed and notarized through Apple. Never
install an artifact presented as an official release from an untrusted mirror.
