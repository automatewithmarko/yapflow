# Third-party model notices

YapFlow downloads optional local model files directly to the user's device. Model data is not bundled into YapFlow's installers.

## Qwen3-4B-GGUF

Agent Mode uses `Qwen3-4B-Q4_K_M.gguf` from the Qwen3-4B-GGUF repository published by the Qwen team. The model is licensed under Apache License 2.0. See:

- https://huggingface.co/Qwen/Qwen3-4B-GGUF
- https://huggingface.co/Qwen/Qwen3-4B-GGUF/blob/main/LICENSE

## Whisper models

Speech transcription uses a quantized Whisper model distributed by the whisper.cpp project. Whisper model and implementation licensing information is available at:

- https://github.com/ggml-org/whisper.cpp
- https://github.com/openai/whisper

## llama.cpp

YapFlow embeds llama.cpp through the `llama-cpp-2` Rust bindings for local model inference. llama.cpp is licensed under the MIT License:

- https://github.com/ggml-org/llama.cpp
